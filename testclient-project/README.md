# TestClient 2.0 (Fabric, MC 1.21.11)
Bauen: `gradle wrapper` (einmalig, Gradle 9.x) und dann `./gradlew build` -> `build/libs/testclient-2.0.0.jar`
in den mods-Ordner legen (zusammen mit Fabric API). GUI oeffnen: Rechte Shift-Taste.
Mappings: Mojang (officialMojangMappings). fabric_version in gradle.properties anpassen.
Bedienung: Linksklick = Modul an/aus, Rechtsklick = Einstellungen, Slider ziehen, Mausrad scrollt.
Config: config/testclient.json
